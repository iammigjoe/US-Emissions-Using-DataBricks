US Emissions Analysis Dashboard (Databricks)
Project Overview

This project analyzes greenhouse gas emissions across the Continental United States using Databricks. The data was queried and transformed to produce key insights and visualized through an interactive dashboard.

Business Problem

Organizations and policymakers need clear, data-driven insights to understand where emissions are concentrated and how they relate to population distribution. This project helps identify high-emission states, regional disparities, and overall emission trends to support environmental strategy, policy planning, and sustainability reporting.

Key Analyses
	•	Emissions across the Continental US
	•	Emissions vs Population
	•	Top 10 states by emission percentage
	•	Total emissions in million tons of CO₂e

Skills Learned
	•	Data querying and aggregation
	•	Analytical thinking on environmental data
	•	Building KPI-driven dashboards
	•	Translating raw data into business insights

Technologies Used
	•	Databricks
	•	Apache Spark / Spark SQL
	•	Databricks Dashboards

Présentation du Projet

Ce projet analyse les émissions de gaz à effet de serre aux États-Unis continentaux à l’aide de Databricks. Les données ont été interrogées et transformées afin de produire des indicateurs clés, puis visualisées dans un tableau de bord interactif.

Problématique Métier

Les décideurs publics et les entreprises ont besoin d’analyses claires pour identifier les zones à forte émission et comprendre le lien entre émissions et population. Ce projet permet de mettre en évidence les États les plus émetteurs et les disparités régionales afin d’orienter les politiques environnementales et les stratégies de durabilité.

Analyses Réalisées
	•	Émissions sur l’ensemble des États-Unis continentaux
	•	Comparaison émissions vs population
	•	Top 10 des États par pourcentage d’émissions
	•	Total des émissions en millions de tonnes de CO₂e

Compétences Acquises
	•	Requêtes et agrégations de données
	•	Analyse de données environnementales
	•	Conception de tableaux de bord décisionnels
	•	Valorisation des données pour la prise de décision

Technologies Utilisées
	•	Databricks
	•	Apache Spark / Spark SQL
	•	Tableaux de bord Databricks
